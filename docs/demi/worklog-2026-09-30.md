## Risks found

1. Branch divergence: using `development` would mix stale/conflicting work. Mitigation: branch from the current V2 release line.
2. Meta receiver tenant hardcoding: unsafe for SaaS. Mitigation: server-side channel-to-tenant mapping before Phase 5.
3. Double replies during parallel operation: Asistian and Demi must not independently answer the same conversation. Mitigation: demo/shadow/pilot/active routing modes.
4. Model-authorized mutations: prompt-only confirmation is insufficient. Mitigation: server-created pending-action token + explicit confirmation + revalidation.
5. Stale business facts in conversation context. Mitigation: never treat model memory as operational truth; query Studio Flow tools again.
6. PII leakage. Mitigation: purpose-built DTOs, opaque references, `store:false`, redacted logs.
7. Cost drift. Mitigation: actual token telemetry + dated pricing + hard tenant budget controls.
