## Correcciones cerradas

- Facebook usa el flujo actual de pago antes de datos, con identidad y conversaciones acotadas al estudio.
- Repetir el comprobante o la reserva conserva una sola ficha, reserva y pago.
- Aviso de posible cancelación: se evita duplicarlo incluso cuando el modelo expresa primero la condición.
- Enlace público: se bloquean dominio ajeno, importe o moneda desactualizados, enlace desactivado y acceso sin permisos.
