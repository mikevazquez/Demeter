## Dependencias

El usuario indicó usar por ahora la app de Meta. Continuar por la integración Meta de Demeter; no se infiere un destinatario real. Se requiere un preview actualizado y servicio/modelo configurados: este executor no tiene SUPABASE_SERVICE_ROLE_KEY ni OPENAI_API_KEY. El conector SQL permitió pruebas operativas sin sustituir el modelo ni la entrega externa. Grupos, seguimientos y crédito de prueba están implementados en esta rama. El usuario definió el inicio desde la primera clase reservada. Los controles administrativos están en `/admin/mas/demi/seguimientos` y `/admin/mas/demi/uat`.

Diagnóstico de Meta en Sandbox: proveedor meta_whatsapp habilitado y predeterminado, webhook_configured=true, pilot_contact_configured=true y connection_repair_required=false. Esto acredita configuración registrada; no se ejecutó envío ni recepción externa ni se verificó el token contra Graph API.

## Segunda ejecución: cierre autorizado

Se aplicaron ocho migraciones nuevas exclusivamente al Sandbox y se desplegó `demi-followup-worker` con autenticación propia por clave de servicio o token de despacho verificado mediante RPC. El cron procesa cada cinco minutos únicamente estudios habilitados; excluye estudios UAT. En estudios sintéticos, el worker captura mensajes y permite simular el reloj. El proveedor devuelve aceptación, no prueba de entrega final.

Pruebas: seis variantes de grupos, cuatro nuevas de crédito de prueba, siete de seguimientos y las dieciocho variantes anteriores vuelven a pasar (35 variantes distintas). La suite de crédito repite cinco controles grupales como preparación. Evidencia estructurada en `demi-2-completion-evidence.json`. Se mantuvieron transacciones con ROLLBACK y datos ficticios.

La revisión de seguridad detectó tres RPC existentes de servicio con permisos públicos innecesarios; se revocó EXECUTE para anon y authenticated, conservando service_role. Las funciones administrativas nuevas exigen usuario y capacidad del estudio; las tablas nuevas tienen RLS. Avisos del linter sobre SECURITY DEFINER administrativo requieren revisar el control interno, no eliminar indiscriminadamente funciones legítimas: https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable
